CLOUD STUDENT MANAGEMENT SYSTEM - ENHANCED UI
===============================================

Run:
1. Open CMD in this folder.
2. python app.py
3. Open http://127.0.0.1:5000

For AWS EC2:
- Copy the project to Ubuntu EC2.
- Install Python/Flask.
- Allow TCP port 5000 in the security group for the lab demonstration.
- Run: python3 app.py
- Open: http://EC2-PUBLIC-IP:5000

Features:
- Modern responsive dashboard
- Student add/view/delete
- Search/filter
- Student and course statistics
- SQLite database
- Health check
